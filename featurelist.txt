7. LOANS  [NEW]
===============================================================================
- Raise a loan against any active booking
  - Applicant name and relation (self, spouse, father, mother, sibling, other)
  - Bank, application number
  - Loan type: home, plot, balloon, bridge
  - Loan amount, margin, property valuation, interest rate, tenure, EMI
- Lifecycle: Applied, Documents Pending, In Progress, Sanctioned, Disbursed,
  Rejected, Closed
- Guard rails
  - Loan amount cannot exceed the sale value
  - Cannot raise a loan against a cancelled booking
  - Sanction date required before a disbursement can be recorded
  - Rejected/closed loans cannot carry a disbursement date
- Stuck detection
  - 30-day per-stage threshold; SLA references: 21 days sanction, 45 disbursement
  - Ageing restarts on each stage change
  - Disbursed/rejected/closed loans are never reported as stuck
  - Stuck loans sort to the top of the list
- Pipeline reporting
  - Open / stuck / disbursed counts
  - Total disbursed and pending-disbursement value
  - Value by stage and by bank
  - "Bookings needing a loan" worklist
- UI: /loans page + loan card embedded in booking detail
